# Wearable stress and task context

Analysis code for *Does Physiology Improve Prediction of Self-Reported Stress Beyond Task Context?*

The StressID scripts extract the 20-second physiology windows, generate held-out predictions, evaluate predictions at the participant–task level and reproduce the comparisons for manuscript Tables 2–5. The WESAD script checks the timing and scoring of the questionnaire measurements in the supplementary analysis. See [figure instructions](figures/README.md) for Figures 1 and 2.

## Data access

- [StressID](https://project.inria.fr/stressid/) is available from its providers under their data-use conditions. Use the dataset folder that contains `Physiological/`, `self_assessments.csv`, `labels.csv` and `labels_supplementary.csv`. The distribution used for the manuscript had 710 physiological recordings, so confirm coverage if a different release is used.
- [WESAD](https://ubi29.informatik.uni-siegen.de/usi/data_wesad.html) is available from the original provider. See the [WESAD instructions](wesad/README.md) for the questionnaire alignment calculation.
- [EmpathicSchool](https://doi.org/10.5281/zenodo.15556502) is available under the provider's conditions. This package covers StressID and the WESAD questionnaire analysis. The EmpathicSchool sensitivity analysis uses a separate pipeline.

Keep downloaded data and generated participant-level outputs in a local working directory. The scripts read the official data obtained by the researcher and write derived files locally.

## StressID analysis

Use Python 3.10 and install `requirements.txt`. Run the following commands from the repository root. Replace `STRESSID_DATASET` with the path to the dataset folder described above.

```text
python -m pip install -r requirements.txt
python -B stressid_pipeline.py --stressid-root "STRESSID_DATASET" --out-dir runs/features --features-only
python -B paper_results_v2/scripts/stressid_reanalysis.py --feature-dir runs/features --stressid-root "STRESSID_DATASET" --out-dir runs/predictions
```

Create `runs/context` and copy `paper_results_v2/addendum_context_incremental_value/analysis_plan_frozen.md` into it without editing the plan. Run the context and subject-and-task analyses in this order:

```text
python -B paper_results_v2/scripts/context_incremental_analysis.py --feature-csv runs/features/stressid_features.csv --retained-predictions runs/predictions/stressid_predictions.parquet --source-dir runs/predictions --out-dir runs/context --bootstrap 2000 --run-disjoint
python -B paper_results_v2/scripts/subject_task_disjoint_all_models.py --features runs/features/stressid_features.csv --retained-predictions runs/predictions/stressid_predictions.parquet --prior-rf-predictions runs/context/subject_task_disjoint_predictions.parquet --source-dir runs/predictions --out-dir runs/transfer --bootstrap 2000
```

The final command uses the random-forest predictions from the preceding command as a cross-check. Run the full scripts in fresh output directories. The full model fits take longer than regenerating tables or figures from existing outputs.

| Manuscript result | Output |
| --- | --- |
| Table 2 and Figure 1 | `runs/context/context_incremental_results.csv` |
| Table 3 | `runs/context/residual_prediction_results.csv` |
| Table 4 and Figure 2 | `runs/transfer/subject_task_disjoint_all_models.csv` and `runs/transfer/subject_task_disjoint_paired_differences.csv` |
| Table 5 | `runs/context/uncertainty_by_unit.csv` |

The manuscript run used Python 3.10.0 and PyTorch 2.5.1 (`cu121` build). Only load sequence archives generated by the feature extraction script. See the original frozen plan for validation splits, outcome definitions and uncertainty calculations.
